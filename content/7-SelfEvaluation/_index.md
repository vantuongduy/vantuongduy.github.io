# Self-Assessment

After completing the **Enterprise HelpDesk on AWS** workshop, participants will have gained valuable knowledge and practical experience in designing, deploying, and operating a cloud-based application. Throughout the hands-on exercises, multiple AWS services are integrated into a complete solution that delivers scalability, high availability, monitoring, and security.

## 7.1. Knowledge Gained

Throughout this workshop, participants learn how to design and implement an application architecture on AWS while understanding the role of each AWS service and how they work together within a complete system.

The knowledge gained includes:

- Understanding the overall architecture of the Enterprise HelpDesk system on AWS.
- Understanding how to design network infrastructure using Amazon VPC.
- Learning how to deploy a database using Amazon RDS for SQL Server.
- Understanding how AWS Secrets Manager protects sensitive database connection information.
- Understanding how IAM roles and IAM instance profiles provide secure access to AWS services.
- Learning how to deploy an ASP.NET Core application using AWS Elastic Beanstalk.
- Understanding how the Application Load Balancer (ALB) and Amazon EC2 Auto Scaling work together to provide scalability and high availability.
- Learning how to use Amazon CloudWatch to monitor application and infrastructure performance.
- Understanding the role of AWS WAF in protecting web applications from internet-based threats.
- Understanding how AWS CloudTrail records and audits activities across the AWS environment.

---

## 7.2. Skills Acquired

In addition to technical knowledge, this workshop helps participants develop practical skills required to deploy and manage applications in a cloud environment.

The skills acquired include:

- Designing and implementing cloud architectures.
- Configuring and managing AWS services.
- Deploying ASP.NET Core applications in a production-like environment.
- Connecting applications to Amazon RDS databases.
- Managing sensitive information using AWS Secrets Manager.
- Monitoring applications and infrastructure with Amazon CloudWatch.
- Configuring network security using security groups and AWS WAF.
- Troubleshooting, validating, and resolving deployment issues.

---

## 7.3. Outcomes

Upon completing this workshop, the Enterprise HelpDesk system is successfully deployed on the AWS Cloud.

Core application features—including user authentication, ticket creation, request processing, user management, and activity tracking—operate reliably. In addition, AWS services such as Amazon VPC, Amazon RDS for SQL Server, AWS Elastic Beanstalk, the Application Load Balancer, Amazon EC2 Auto Scaling, Amazon CloudWatch, AWS WAF, and AWS CloudTrail are correctly configured and function as intended within the solution architecture.

The completed deployment demonstrates that the solution satisfies key cloud architecture requirements, including scalability, security, monitoring, and high availability.

---

## 7.4. Limitations

Although the workshop successfully covers the complete deployment process, there are several areas that could be improved in future iterations.

Current limitations include:

- Amazon RDS Multi-AZ deployment has not been implemented for enhanced fault tolerance.
- A CI/CD pipeline has not been integrated to automate application deployment.
- Amazon ElastiCache has not been implemented to improve application performance.
- Advanced alerting and notifications using Amazon SNS have not been configured.
- Long-term AWS cost optimization strategies have not yet been implemented.

---

## 7.5. Future Enhancements

The solution can be further enhanced by integrating additional AWS services to improve performance, security, automation, and operational efficiency.

Potential future enhancements include:

- Implementing CI/CD using GitHub Actions or AWS CodePipeline.
- Using Amazon ElastiCache to accelerate data access.
- Configuring Amazon RDS Multi-AZ for higher availability.
- Building a notification system using Amazon SNS.
- Deploying Amazon CloudFront to improve application performance and reduce latency.
- Integrating AWS Shield Advanced to provide enhanced protection against DDoS attacks.

---

## Conclusion

This workshop enables participants to apply cloud computing concepts by deploying a real-world application on AWS. Through the design, deployment, and validation of the Enterprise HelpDesk system, participants gain a comprehensive understanding of individual AWS services and how they integrate to form a scalable, secure, and highly available cloud architecture.

The knowledge and hands-on experience gained throughout this workshop provide a solid foundation for designing, deploying, and operating enterprise applications on AWS in real-world production environments.
