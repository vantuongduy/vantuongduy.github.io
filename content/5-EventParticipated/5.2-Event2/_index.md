# Introduction

Mini Meetup – First Cloud AI Journey was a community event for students, software engineers, and technology enthusiasts who are learning or working with Amazon Web Services (AWS). The event focused on sharing practical experiences, introducing emerging technologies, and presenting real-world lessons learned from enterprise projects.

Through sessions delivered by industry speakers, attendees had the opportunity to explore a wide range of topics, including cloud infrastructure, DevOps, cybersecurity, artificial intelligence, and career development in Cloud Computing.

---

# Event Objectives

- Share practical experience in deploying solutions on AWS.
- Introduce emerging technologies in Cloud Computing and DevOps.
- Present real-world projects and case studies.
- Provide updates on AWS security and artificial intelligence technologies.
- Strengthen connections within the Cloud Computing community.

# Event Sessions

## 1. Docker – A Containerization Technology

**Speaker:** Bao Huynh

### Key Highlights

- Introduced Docker and container architecture.
- Compared containers with virtual machines.
- Explained Docker images, containers, and Docker Registry.
- Demonstrated the process of building, running, and deploying applications with Docker.
- Discussed Docker's role in DevOps and cloud application deployment.

---

## 2. Combining AWS WAF with Machine Learning for Cyber Attack Detection on AWS

**Speaker:** Le Hoang Gia Dai

### Key Highlights

- Introduced AWS Web Application Firewall (AWS WAF).
- Reviewed common web application attack vectors.
- Demonstrated how machine learning can detect abnormal traffic patterns.
- Explained automated threat detection and mitigation.
- Showed how AWS WAF enhances web application security on AWS.

---

## 3. Multiplayer in the Cloud – Connecting Godot Clients with AWS WebSockets

**Speaker:** Nguyen Quoc Bao

### Key Highlights

- Introduced multiplayer cloud architecture.
- Demonstrated connecting Godot clients through AWS WebSockets.
- Explained real-time data synchronization.
- Discussed backend architecture for online games.
- Presented WebSocket use cases for real-time applications.

## 4. Building Effective Teamwork

**Speaker:** Truong Phuoc

### Key Highlights

## 5. AWS Neptune for Building a Graph Knowledge Base for GraphRAG
