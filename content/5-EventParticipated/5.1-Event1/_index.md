# Introduction

AWS First Cloud AI Journey Community Day 2026 was a community event for technology enthusiasts interested in Cloud Computing and Artificial Intelligence (AI). The event brought together AWS experts, industry speakers, and members of the technology community to share real-world implementation experiences, discuss the latest AI trends, and showcase innovative services within the Amazon Web Services (AWS) ecosystem.

Through a series of in-depth technical sessions, attendees gained valuable insights into modern cloud architectures, enterprise AI applications, and best practices for building solutions on AWS.

---

# Event Objectives

- Share real-world experiences in deploying AI solutions on AWS.
- Introduce emerging trends in Cloud Computing and Generative AI.
- Present modern AI architectures for enterprise environments.
- Showcase real-world case studies from enterprises and the AWS community.
- Provide networking and learning opportunities within the AWS Vietnam community.

# Event Sessions

## 1. Enterprise-Grade Multi-Agent Architecture

**Speaker:** Cat Vy – VPBank

### Key Highlights

- Introduced a credit scoring solution for startup businesses.
- Explained the limitations of single-agent AI systems when solving complex, multi-domain problems.
- Presented a multi-agent architecture consisting of specialized agents, including Financial Analyst, Market Analyst, Team Evaluator, Risk Assessor, Compliance Agent, and Manager.
- Demonstrated the use of Amazon Bedrock Guardrails to validate inputs, control AI processing, and safeguard outputs.
- Implemented the solution using AWS Lambda, Amazon Elastic Container Registry (Amazon ECR), Amazon API Gateway, and AgentCore Runtime.

### Results

- Reduced application processing time from **2–3 weeks to only 2–4 hours**.
- Reduced processing costs by approximately **95%**.
- Achieved an estimated **200–300% return on investment (ROI) over three years**.

---

## 2. The Uncertainty of Large Language Models (LLMs)

**Speaker:** Dao Duc – Cloud Kinetics

### Key Highlights

- Explained why Large Language Models (LLMs) remain non-deterministic even when the temperature parameter is set to zero.
- Discussed sources of non-determinism, including floating-point computation and inference batching.
- Introduced techniques for improving response consistency, such as using Temperature = 0.1, Majority Voting, Structured Output, and Function Calling.
- Emphasized designing AI systems that embrace probabilistic behavior rather than expecting identical outputs for every request.

---

## 3. Amazon CloudFront – From Edge to Origin

**Speaker:** Nguyen Tuan Thinh

### Key Highlights

- Introduced Amazon CloudFront within modern cloud architectures.
- Improved performance using HTTP/3, Gzip compression, and Brotli compression.
- Protected origin infrastructure using Origin Access Control (OAC) and Amazon VPC origins.
- Integrated AWS Shield to mitigate Distributed Denial of Service (DDoS) attacks.
- Reduced data transfer costs while improving content delivery performance.

---

## 4. Building Enterprise AI Assistants with Amazon Q

**Speaker:** Pham Nguyen Hai Anh

### Key Highlights

- Introduced Amazon Q and the concept of Agentic AI.
- Demonstrated integration with more than 40 enterprise data sources.
- Automated workflows for Sales, Marketing, Human Resources (HR), and Customer Support.
- Combined Amazon Bedrock with enterprise access control and data governance mechanisms.
- Showcased practical examples of AI-assisted business operations.

---

## 5. Context Is Everything – Building a Second AI Brain

**Speaker:** Truong Tan Tinh

### Key Highlights

- Explained the critical role of context in AI applications.
- Introduced a context framework consisting of Goals, Relevant Information, Constraints, and Success Criteria.
- Shared common prompt engineering mistakes.
- Presented the "Second AI Brain" architecture using Amazon S3, a vector database, and Amazon Bedrock.

---

## 6. A 36-Hour Hackathon Journey – The UTMorpho Project

**Speaker:** Team VIB

### Key Highlights

- Shared the experience of participating in the 36-hour LotusHacks competition.
- Introduced the UTMorpho project architecture:
  - Frontend hosted on Amazon S3 and Amazon CloudFront.
  - Backend powered by Amazon API Gateway and AWS Lambda.
  - AI pipeline built using Amazon Bedrock.
- Discussed development challenges such as token limits, overgeneration, and scope creep.
- Shared practical experience in transforming an AI concept into a production-ready solution.

# Key Takeaways

After attending the event, I gained several valuable insights:

- Enterprise AI is evolving from single-agent systems toward multi-agent architectures.
- High-quality context is more valuable than simply providing large amounts of information to AI models.
- LLM outputs should be treated as probabilistic rather than completely deterministic.
- Amazon CloudFront is much more than a Content Delivery Network (CDN); it is also an essential component for performance optimization and security.
- Amazon Bedrock, AWS Lambda, Amazon API Gateway, and Amazon ECR play critical roles in modern AI application development on AWS.
- Enterprise AI solutions should be designed with scalability, governance, and security in mind from the very beginning.

# Reflections

This was the first AWS community event I attended and a valuable opportunity to explore emerging topics in Cloud Computing and Artificial Intelligence for enterprise environments.

Through presentations delivered by experts from VPBank, Cloud Kinetics, the AWS community, and leading technology companies, I gained a much deeper understanding of how services such as Amazon Bedrock, Amazon CloudFront, AWS Lambda, Amazon API Gateway, Amazon S3, and Amazon ECR are applied in real-world production systems.

The sessions on enterprise-grade multi-agent architecture and the UTMorpho project were particularly inspiring, providing practical insights into building scalable, secure, and production-ready AI solutions.
