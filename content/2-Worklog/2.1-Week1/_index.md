## 🎯 Week 1 Objectives

- Set up and configure an AWS account for the internship.
- Configure AWS Budgets to monitor and control cloud expenses.
- Understand user management and access control using AWS Identity and Access Management (IAM).
- Build a basic networking environment using Amazon VPC.
- Configure Public Subnets, Private Subnets, Route Tables, and an Internet Gateway.

## 🏆 Achievements

- Successfully created and configured a personal AWS account.
- Configured AWS Budgets to monitor and control cloud spending.
- Successfully created IAM Users, IAM Groups, IAM Roles, and IAM Policies.
- Applied the Principle of Least Privilege when managing permissions.
- Successfully built an Amazon VPC with Public and Private Subnets.
- Configured Route Tables and an Internet Gateway for the Public Subnet.
- Gained a solid understanding of the fundamental networking architecture on AWS.

---

## 💡 Key Takeaways

- Understood the process of creating and securing an AWS account.
- Learned how to monitor cloud costs using AWS Budgets.
- Understood the roles of IAM Users, IAM Groups, IAM Roles, and IAM Policies.
- Learned how to apply the Principle of Least Privilege when granting permissions.
- Understood how to separate a network into Public and Private Subnets.
- Understood the roles of Route Tables and Internet Gateways within an Amazon VPC.
- Established a strong AWS networking foundation for deploying cloud resources in the following weeks.
