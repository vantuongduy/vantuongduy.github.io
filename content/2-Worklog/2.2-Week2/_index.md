## 🎯 Week 2 Objectives

- Deploy and manage Amazon EC2 virtual servers.
- Connect to and work with the Linux operating system on Amazon EC2.
- Understand how to grant permissions to EC2 instances using IAM Roles.
- Configure Security Groups to control network traffic.

## 🏆 Achievements

- Successfully launched and managed an Amazon EC2 instance.
- Successfully connected to the EC2 instance using SSH.
- Practiced managing the EC2 instance lifecycle, including starting, stopping, and rebooting.
- Successfully created and attached an IAM Role to the Amazon EC2 instance.
- Accessed AWS resources securely from EC2 without storing Access Keys.
- Configured Security Groups to control SSH and HTTP traffic.
- Performed basic AWS resource management tasks using the AWS CLI.

---

## 💡 Key Takeaways

- Understood the process of launching and managing Amazon EC2 instances.
- Learned how to connect to a Linux server using SSH.
- Understood the role of a Key Pair in secure authentication.
- Learned how to assign IAM Roles to EC2 instances for secure access to AWS resources.
- Understood the purpose of Security Groups in controlling network traffic.
- Learned how to use the AWS CLI to inspect and manage AWS resources.
