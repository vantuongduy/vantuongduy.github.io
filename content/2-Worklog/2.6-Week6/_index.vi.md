## 🏆 Thành tích đạt được

- Cấu hình thành công Amazon CloudWatch Logs để theo dõi nhật ký hệ thống.
- Tạo Dashboard trên Amazon Managed Grafana để trực quan hóa dữ liệu.
- Quản lý tài nguyên hiệu quả bằng AWS Resource Groups và Tag.
- Kết nối thành công EC2 với AWS Systems Manager.
- Truy cập và quản lý EC2 thông qua Session Manager mà không cần SSH.
- Hiểu quy trình giám sát, quản lý và vận hành hệ thống trên AWS.

## 💡 Kiến thức rút ra

- Hiểu vai trò của Amazon CloudWatch Logs trong việc giám sát hệ thống.
- Biết cách trực quan hóa dữ liệu bằng Amazon Managed Grafana.
- Hiểu lợi ích của việc quản lý tài nguyên bằng Resource Groups và Tag.
- Biết cách sử dụng AWS Systems Manager để quản trị máy chủ từ xa.
- Có nền tảng để triển khai các hệ thống AWS có khả năng giám sát và quản trị hiệu quả.
