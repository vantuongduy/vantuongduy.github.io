- Xây dựng thành công mô hình Event-driven với AWS Lambda.
- Tạo API bằng Amazon API Gateway và kết nối với DynamoDB.
- Cấu hình và xác thực người dùng bằng Amazon Cognito.
- Triển khai ứng dụng thành công trên AWS Elastic Beanstalk.
- Thực hiện truy vấn dữ liệu bằng Amazon Athena.
- Xây dựng báo cáo trực quan với Amazon QuickSight.
- Làm quen với môi trường Machine Learning trên Amazon SageMaker.

## 💡 Kiến thức rút ra

- Hiểu nguyên lý hoạt động của kiến trúc Event-driven trên AWS.
- Biết cách kết hợp Lambda, API Gateway và DynamoDB để xây dựng ứng dụng Serverless.
- Nắm được cơ chế xác thực người dùng bằng Amazon Cognito.
- Hiểu quy trình triển khai ứng dụng với Elastic Beanstalk.
- Biết cách phân tích dữ liệu bằng Amazon Athena và trực quan hóa với QuickSight.
- Có kiến thức cơ bản về nền tảng Machine Learning trên Amazon SageMaker.
