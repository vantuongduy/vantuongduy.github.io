## 🎯 Week 3 Objectives

- Understand the automatic resource scaling mechanism using Amazon EC2 Auto Scaling.
- Learn how to distribute traffic using Elastic Load Balancing.
- Monitor AWS resources and system performance with Amazon CloudWatch.
- Configure domain names and DNS records using Amazon Route 53.
- Practice managing AWS resources through the AWS Command Line Interface (AWS CLI).

## 💡 Key Takeaways

- Understood the role of Amazon EC2 Auto Scaling in maintaining system scalability and availability.
- Learned how to use Elastic Load Balancing to distribute incoming traffic efficiently.
- Understood how Target Groups and Health Checks work together to maintain application availability.
- Learned how to configure scaling policies based on Amazon CloudWatch metrics.
- Understood how Amazon CloudWatch is used to monitor resource performance.
- Learned how to manage domain names and DNS records with Amazon Route 53.
- Gained hands-on experience using the AWS Command Line Interface (AWS CLI) to inspect and manage AWS resources.
