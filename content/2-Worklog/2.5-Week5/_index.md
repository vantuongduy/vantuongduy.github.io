## 🎯 Week 5 Objectives

- Learn the process of migrating virtual machines to AWS using VM Import/Export.
- Practice database migration using AWS Database Migration Service (AWS DMS).
- Gain hands-on experience with AWS Schema Conversion Tool (AWS SCT).
- Deploy event-driven applications using AWS Lambda.
- Learn backup and disaster recovery solutions with AWS Elastic Disaster Recovery.

## 💡 Key Takeaways

- Understood the migration process from on-premises environments to AWS.
- Learned how to use AWS Database Migration Service (AWS DMS) to migrate data between database management systems.
- Understood the role of AWS Schema Conversion Tool (AWS SCT) in database schema conversion.
- Learned the Serverless computing model and how to develop and deploy AWS Lambda functions.
- Understood how AWS Elastic Disaster Recovery helps ensure business continuity and disaster recovery.
