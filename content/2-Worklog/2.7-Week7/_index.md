## 🎯 Week 7 Objectives

- Learn Infrastructure as Code (IaC) deployment using AWS CloudFormation.
- Gain hands-on experience with the AWS Cloud Development Kit (AWS CDK).
- Explore cost optimization strategies on AWS.
- Practice creating automated snapshots using Amazon EBS Data Lifecycle Manager.
- Monitor network traffic using VPC Flow Logs.
- Become familiar with AWS Toolkit for Visual Studio Code.

- Understood the role of Amazon EBS snapshots in backup and data protection.

- Became familiar with AWS Toolkit for Visual Studio Code, enabling AWS resource management and deployment directly from the development environment.
