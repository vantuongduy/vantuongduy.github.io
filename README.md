# Enterprise HelpDesk AWS Portfolio Workshop

This project contains all portfolio content from the original AWS Portfolio project, migrated into the FCJ Hugo Workshop template.

## Important paths

- Hugo configuration: `config.toml`
- English content: `content/**/_index.md`
- Vietnamese content: `content/**/_index.vi.md`
- Workshop images: `static/images/workshop/`
- AWS architecture image: `static/images/workshop/aws.jpg`
- GitHub Actions workflow: `.github/workflows/hugo.yml`

## Local preview

```powershell
hugo server -D
```

Open `http://localhost:1313`.
